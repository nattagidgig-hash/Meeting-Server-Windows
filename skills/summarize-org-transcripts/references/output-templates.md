ใช้หัวข้อและภาษาในแม่แบบองค์กรที่ได้รับก่อนแม่แบบนี้ คงกติกาความถูกต้องและการอ้างอิงเสมอ หากแม่แบบไม่มีช่องรอยืนยัน ให้เพิ่มหมายเหตุท้ายรายงานแทนการซ่อนข้อจำกัด

## การบรรยาย

คง metadata, สถานะร่าง และรูปแบบรายงาน ใช้หัวข้อต่อไปนี้:
1. สาระสำคัญ
2. แนวคิดและคำอธิบายแยกหัวข้อ
3. ตัวอย่าง วิธีการ หรือขั้นตอนที่วิทยากรกล่าวถึง
4. เงื่อนไข ข้อจำกัด และข้อควรระวังที่กล่าวถึง
5. ช่วงถาม–ตอบและคำถามค้าง (เมื่อมี)
6. จุดที่ต้องตรวจทาน
ไม่สร้าง Action Items ขององค์กรจากคำแนะนำทั่วไปของวิทยากร แยกความเห็นผู้บรรยายออกจากข้อเท็จจริงที่ตรวจสอบภายนอกแล้ว

## ระดมสมอง

ใช้ภาพรวม → เป้าหมาย/ปัญหาที่กล่าวถึง → ไอเดียและผู้เสนอ → เหตุผล/ข้อดีข้อจำกัดตามที่อภิปราย → ทางเลือกที่เลือกจริงถ้ามี → งานที่มอบหมายจริง → ประเด็นค้าง/รอยืนยัน
อย่าทำตารางให้ดูเหมือนคะแนนหรือจัดอันดับ หากต้นฉบับไม่มีการประเมินนั้น

## สัมภาษณ์

ใช้ภาพรวม → บริบทผู้ให้สัมภาษณ์เท่าที่ระบุ → ประเด็นหรือคำถามหลักและคำตอบ → ความต้องการ/ปัญหา/ตัวอย่างที่ให้มา → สิ่งที่ขัดแย้งหรือยังต้องถามต่อ → จุดที่ต้องตรวจทาน
อย่าเหมารวมคำพูดของผู้ให้สัมภาษณ์คนเดียวเป็นข้อมูลของลูกค้าหรือคนทั้งกลุ่ม ไม่แต่งคำพูดตรงหรือแรงจูงใจ

## โหมดย่อ / เฉพาะมติ / เฉพาะงาน

- ย่อ: metadata ที่จำเป็น + ภาพรวม 3–7 ข้อหรือน้อยกว่าตามสาระ + มติ/งานสำคัญ + ข้อจำกัดที่กระทบความเข้าใจ คงข้อจำกัดและตัวเลขสำคัญ
- เฉพาะมติ: สถานะร่าง + ตารางมติ + ประเด็นรอยืนยันที่เกี่ยวข้อง ไม่พ่วงข้อเสนอที่ยังไม่ตกลง
- เฉพาะงาน: สถานะร่าง + ตารางงาน + ประเด็นรอยืนยันที่เกี่ยวข้อง
- ไม่ปิดท้ายด้วยคำถาม “ต้องการให้ปรับอะไรอีกไหม” โดยอัตโนมัติ
