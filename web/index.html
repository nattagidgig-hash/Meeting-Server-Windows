  1. 1ตรวจข้อความชื่อ ตัวเลข มติ
  2. 2ตรวจรายงานแก้ถ้อยคำให้ตรงต้นฉบับ
  3. 3อนุมัติและส่งออกWord, ข้อความ, JSON

ตรวจชื่อคน ตัวเลข และมติสำคัญก่อนกดสรุป การแก้ในช่องนี้ไม่ทับข้อความต้นฉบับ

2. ร่างรายงาน

AI ไม่ได้อนุมัติเอกสารแทนคน การแก้รายงานที่อนุมัติแล้วจะเปลี่ยนกลับเป็นฉบับร่าง

ส่งออกเอกสาร

Word.docx Word รุ่นเก่า.doc ข้อความ.txt JSONข้อมูลดิบ

ดาวน์โหลดและพิมพ์ข้อมูลฉบับที่บันทึกแล้ว หากแก้ข้อความให้บันทึกก่อน

ผู้ดูแลระบบ

ตั้งค่า Claude API

ใช้ Key จาก Claude Console และบัญชีหรือ Workspace ที่องค์กรอนุมัติ

ยังไม่ได้ตรวจสอบการเชื่อมต่อ กดตรวจสอบเพื่อยืนยันว่าบัญชีนี้เรียก Claude API ได้จริง

เชื่อมต่อบัญชีและโมเดล

เปิด Claude Console

Claude Team กับ API เป็นคนละส่วน ต้องสร้าง API key ใน Console และเชื่อมเครดิต Team ตามเงื่อนไขของแพ็กเกจ

อ่านเฉพาะรายการโมเดล ไม่ส่งข้อความประชุม

ข้อความจะออกไปประมวลผลที่ Anthropic

บริการเชิงพาณิชย์ไม่ใช้ข้อมูลฝึกโมเดลโดยค่าเริ่มต้น แต่มีข้อยกเว้นเมื่ออนุญาตหรือส่ง feedback และระยะเก็บข้อมูลต้องตรวจตามบริการ รุ่นโมเดล และข้อตกลงจริง Team ไม่ได้แปลว่า Zero Data Retention

ข้อควรทราบ

  • เว้นช่อง Key ว่างเพื่อใช้ Key เดิม เมื่อบันทึกแล้วจะไม่ส่ง Key กลับมาแสดง
  • ไม่เก็บ Key ใน localStorage หรือรายการประชุม
  • การตรวจ Key ไม่อ่านเสียงหรือข้อความประชุม และไม่ยืนยันว่าวงเงินสรุปเพียงพอ
  • บน Windows Key เข้ารหัสผูกกับเครื่องด้วย DPAPI และต้องจำกัดสิทธิ์โฟลเดอร์ data
  • หากย้ายเซิร์ฟเวอร์ ให้กรอก Key ใหม่
ไฟล์งานเก็บบน Windows Server เครื่องนี้ • การส่งข้อความออกใช้ได้เฉพาะเมื่อผู้ดูแลเปิด API และผู้ใช้ยืนยันรายงานนั้น
